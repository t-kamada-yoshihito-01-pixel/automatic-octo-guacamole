# こども探究AI「いっしょに考えよう」

4年生を想定した、**答えをすぐに教えず、問い返しで考えを深めるAI**の試作です。

## ねらい

- AIを「答えを出す機械」ではなく「考える相手」にする
- 1回の返答で中心となる問いを1つにする
- 子どもの考えを受け止めてから、理由・根拠・別の視点・次の問いへ進める
- 答えの丸写しをできるだけ防ぐ

## 構成

- `Index.html` … 子どもが使う画面
- `Code.gs` … Google Apps Script側。APIキーを子どもの端末に公開しない
- `Prompt.md` … AIの行動ルール
- `appsscript.json` … GAS設定

## 使い方

1. Google Apps Scriptで新しいプロジェクトを作る
2. このリポジトリの `Code.gs` と `Index.html` と `appsscript.json` を貼り付ける
3. Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」に `OPENAI_API_KEY` を登録する
4. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で公開する
5. 実行ユーザーは自分、アクセス権は学校の運用に合わせて設定する

OpenAIのAPIはResponses APIを利用します。APIキーはHTMLやブラウザ側に書かず、Apps Scriptのスクリプトプロパティだけに保存します。

## 重要

この試作は「AIに子どもの答えを代わりに作らせない」ことを優先しています。学校で本格運用する前に、児童の個人情報を入力しないルール、利用時間、教師による確認、API利用料金、学校の情報セキュリティ規程を確認してください。

## 次の拡張候補

- NHK for School・Yahoo!きっず等の先生が許可したサイトだけを調べる機能
- 探究テーマごとの「問いの深め方」設定
- 教師画面からプロンプトを変更
- 会話ログを保存せず、その場だけで使うモード
- 「今の自分の考え」を最後にまとめる振り返り機能
